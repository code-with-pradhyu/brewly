# ☕ Brewly

> A modern coffee shop landing page built with pure HTML & CSS.

Brewly is a **desktop-only frontend practice project** focused on creating a clean, warm, and elegant coffee shop experience through thoughtful layouts, typography, imagery, and styling.

🌐 **Live Demo:** https://code-with-pradhyu.github.io/brewly/

---

## ✨ Features

- ☕ Modern coffee shop landing page
- 🎨 Warm and elegant visual design
- 🖼️ Coffee & café imagery
- 📋 Menu section
- 🖼️ Gallery section
- 💬 Testimonials
- 📍 Contact & location section
- 🧭 Clean navigation

> 🖥️ **Designed exclusively for desktop viewing. This project is intentionally not responsive.**

---

## 🛠️ Built With

- **HTML5** — Website structure and content
- **CSS3** — Styling, layouts, and visual design
